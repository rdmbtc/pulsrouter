## Puls Deep Research — $0.01/question

Deep web research on any question: multi-source scan (Jina/DDG/Exa/Tavily),
verified brief + cited sources. Settled in USDC on Arc.

### Endpoint

```
GET https://api.pulsmarket.tech/api/x402/research
```

| Query param | Required | Notes                                              |
|-------------|----------|----------------------------------------------------|
| `q`         | yes      | Research question. Free text; URL-encoded.         |

Unpaid requests return `HTTP 402` with the x402 `accepts` payload; paid requests
return `200 application/json`.

### Sample request

```json
POST /proxy HTTP/1.1            // via PulsRouter
Host: localhost:3000
Content-Type: application/json

{ "type": "research", "q": "arc testnet ecosystem" }
```

### Try it — Circle Pay one-liner

```sh
circle services pay "https://api.pulsmarket.tech/api/x402/research?q=what+is+arc+testnet" --address 0xYOUR_AGENT_WALLET --chain ARC-TESTNET --output json
```

Requires a funded Circle agent wallet and a small Gateway float:

```sh
circle gateway deposit --amount 0.5 --address 0xYOUR_AGENT_WALLET --chain ARC-TESTNET --method direct
```

### Why this matters for the Arc ecosystem

Arc's thesis is that agents need a native payment rail, not API keys and invoicing.
Puls Deep Research is the reference consumer of that rail on `eip155:5042002`: any
agent holding USDC can buy a cited research brief in a single HTTP round-trip with
no account, no signup, and sub-cent settlement through Circle Gateway. Every call is
simultaneously a stress-test of Arc's x402 stack (402 challenge → EIP-3009-style
authorization → batched Gateway settlement) and a demonstration that machine-to-machine
commerce works at $0.01 granularity. For sellers it proves the same rails monetize
data APIs directly; for buyers it makes intelligence a line-item cost an agent can
decide about on its own.

## Using these services through PulsRouter

PulsRouter routes to the cheapest healthy provider per type and pays from your
Circle Agent Wallet automatically:

```sh
pulsrouter pay research "arc ecosystem overview"
# or over HTTP:
curl -X POST http://localhost:3000/proxy -H "content-type: application/json" ^
     -d "{\"type\":\"research\",\"q\":\"arc ecosystem\"}"
```

Daily spend caps live in `pulsrouter.config.json`:

```json
{
  "budgets": { "research": 5, "markets": 1 }
}
```

Operational health (gateway float, pending settlements, session expiry, cheaper
alternatives) is exposed as advice:

```
GET http://localhost:3000/advice?wallet=0xYOUR_AGENT_WALLET
```
